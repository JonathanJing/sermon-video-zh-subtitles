# 暗场阅读配色

新访客默认深色；右上角月亮/太阳按钮切换深浅。明确选择保存在当前浏览器，刷新后沿用；存储不可用时，本次页面仍可切换。颜色初始化先于样式绘制，避免先出现浅色整页再变深。

| 用途 | 深色配色 | 设计目的 |
|---|---|---|
| 页面 | `#111819` | 炭灰，降低大面积发光 |
| 卡片 | `#192224` | 以轻微明度差区分区域 |
| 字幕底色 | `#1E2B2B` | 比页面稍亮，便于定位阅读区 |
| 主要文字 | `#DEDFD5` | 暖灰白，保持清晰度 |
| 辅助文字 | `#A3B0AC` | 降低视觉优先级，同时保留可读性 |
| 链接与选中状态 | `#88B7AA` | 低饱和青绿色 |
| 播放按钮 | `#759E92` / `#101B19` | 柔和底色与深色文字 |

字幕使用系统中文无衬线字体、500 字重，保留原有 21–23 px 响应式字号及行距。深色字幕对比度为 **10.88:1**，卡片辅助文字 **7.23:1**，播放按钮文字 **5.92:1**。对比度根据 sRGB 相对亮度计算，属于颜色数值检查；实体手机亮度、使用距离和现场舒适度仍需现场观察。

主题覆盖播放器、周次下拉、全文字幕、制作进度、讲员试听和大纲弹窗。`color-scheme` 同时适配浏览器原生控件。切换不重新加载音频，也不改变播放位置；开关高 44 px，并提供键盘焦点和可读名称。

本次验证：32 个 Python 测试、8 个 Node 测试、脚本语法和 diff 检查通过。浏览器验证默认深色、深浅切换、两种选择刷新保留、播放中切换、大纲弹窗，以及 320 / 390 px 布局无横向溢出。音频、字幕与审核状态沿用上一构建，经哈希比对保持一致。
