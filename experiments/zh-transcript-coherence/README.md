# 中文讲稿连贯性 benchmark（2026-10-25 证道）

实验线，不进生产、不改任何冻结 run。目的：验证 2026-10-26 人工评估里的五项改法，能否改善逐句翻译拼出来的中文讲稿。

## 做法

- 输入：线上 `/content/revelation-jesus-wins-20261025/zh-Hans.json`（447 句，human_reviewed）和 `/english-reference/revelation-jesus-wins-20261025.json`。
- 所有翻译组用同一个模型（Claude CLI `opus`，订阅登录，不用 API key），只有方法不同。`published` 是线上版本（生产模型 Sol + 人工审阅），只作参照。
- 评委看不到组名，按每 25 句一个窗口打 1–10 分（可懂度、口语自然度、忠实度），列出问题；另做全篇不一致检查，并逐条核对人工评估找出的 18 个已知问题（`known_issues_20261025.json`）。评委跑了两遍：Sonnet 和 Opus。
- 代码：可复用部分在 `packages/production/src/tongxing_production/text/coherence.py`，跑法见 `run_benchmark.py` 顶部说明。

| 组 | 方法 |
| --- | --- |
| baseline | 生产现行方法：一句一请求，前 3 后 2 句英文上下文，生产 translator 指令 |
| s1_glossary | baseline + 全篇术语/称谓表（第 1 项） |
| s2_prior | 每 12 句一个窗口，带上前面已译的中文，顺序翻译（第 2 项） |
| s2b_two_pass | s1 再翻一遍，请求里带邻近句的初译中文；每组仍独立并行（第 2 项的折中做法） |
| s3_merge | s2 + 合并接续小句（第 3 项） |
| s5_review | s3 + 每 25 句一窗的连读审核（第 5 项） |
| s4_reading | s5 按段重组的阅读版（第 4 项，只用于讲稿阅读，不用于字幕和配音） |
| p123_wired | 1+2+3 接进 Layer 2 后的实际做法（`text/models.py`）：8 条链按原文顺序跑，链内每 8 句先整段起草，再逐句用生产提示词翻译，输入带术语表（分段生成）、本句草稿、前 8 句最终中文和接续提示。只跑译者，不跑复核，和 baseline、s1 一样 |

## 结果

每格是 Sonnet 评委 / Opus 评委。分数越高越好；问题数、不一致数越少越好。

## 结论

1. **带前文中文（第 2 项）收益最大**：两个评委下可懂度都比 s1 高约 0.4，已知问题修复从 8–11 个升到 15–18 个。两遍翻译的折中做法（s2b）只拿到一小部分收益（Sonnet 评委下约一半，Opus 评委下几乎没有），残句也没减少。
2. **全篇术语表（第 1 项）**单独用收益小，但成本只有一次调用，并且是 s2/s3 统一称谓的前提（例如贝茜=姐姐，耶稣用“祂”，“耶稣使控告者闭口”）。
3. **合并接续小句（第 3 项）**在这篇只触发 5 处（447→442 组），分数与 s2 持平，但全篇不一致最少，修好了 D.A. 卡森、一载二载半载、带着恐惧这几处。Layer 1 切句也已修好空格缩写（`D .A.`）。
4. **连读审核（第 5 项）**在 s3 之上没有可测的收益：11 处改动，7 处是统一龙的代词。暂不建议接入。
5. **阅读版（第 4 项）**作为讲稿阅读最好读：残句 4–6 处（线上版本 43–44 处）。它是新产品形态，要改内容格式和 App 展示。
6. **同方法换模型也有很大差距**：同样逐句翻译，Opus（baseline）比线上版本（Sol + 人工审阅）高 1 分以上。两个评委都是 Claude 系，可能偏好 Claude 的译文，这一条要另做非 Claude 评委或人工盲评确认。

7. **接进 Layer 2 的版本（p123_wired）**比现行做法（baseline）全面更好：可懂度 +0.44 / +0.28，自然度 +0.39 / +0.34，已知问题多修 5 / 4 个，忠实度不降。它拿到 s2/s3 的大部分收益但不是全部（Opus 评委下可懂度 8.56 对 8.89），因为每句最后仍由单独的请求定稿。第一版只带前文中文、不整段起草，只有 7.28 / 8.50 和 9 / 12，所以加了窗口草稿。仍未修好的 K09（D.A. 卡森被切成两句）在 Layer 1 已修，新一周的切句不会再这样；K03（一载二载半载）是一句被切到两条字幕里。

## 限制

- 只有一篇证道、一个翻译模型；每个窗口只评一次，没有重复抽样，分差 0.2 以内视为噪声。
- s2 是“每 12 句顺序翻译、4 段并行”，和 10/19 定下的“逐组独立任务”冲突，接入前需要决定。
- 花费：翻译加两轮评审约 98 美元（Claude CLI 报告的 `total_cost_usd`）。
