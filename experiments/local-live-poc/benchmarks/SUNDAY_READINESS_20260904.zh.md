# 周日实时字幕收敛与验收：2026-09-04

当前结果是**可运行、可恢复、已有真实模型长时证据的受控现场候选**。本轮开发已合入 [PR #10](https://github.com/JonathanJing/sermon-video-zh-subtitles/pull/10)，在合并版本上完成 60 分钟浏览器音频回放。现场声音接入、实体手机及人工语义验收仍未完成，因此不能称为周日现场生产就绪。

工程方向继续成立：独立保存音频，英文 ASR final 作为翻译事实来源，本地模型处理，操作页呈现中文为主的双语字幕，Firebase 公网观看并保留 LAN 退路。当前最大的剩余风险是**语义忠实度与真实场地输入**；增加窗口、合并片段或启用周六材料，都不能凭局部改善直接升级默认。

运行身份为 clean `edaa9d1ec34a5437351a6a97c65fd094eb5dbdc1`，即 PR #10 merge。会话 `20260904T213011.036Z-284aa182` 在 2026-09-04 21:30:11 UTC 开始，正常停止并保存，manifest 时长 **3620.818 秒**。

## 重启恢复：录音保住，字幕仍会有缺口

独立 409.329 秒浏览器回放会话 `20260904T211643.374Z-2599f3a8`，运行与恢复身份均为 clean `063f5f8`。在约 138 秒时从操作页重启 Gateway；同一 session、观看 token 和 MediaRecorder 继续，恢复后中英字幕更新，最终正常停止并 drain。

恢复前录音/PCM 前缀与最终文件一致；WebM、WAV 全量解码通过。独立 WebM 为 409.264 秒、PCM 为 409.200 秒。但重启产生两种不同缺口：

- 135–138 秒的在途 ASR 任务没有终态，也未重新实时处理；该段 PCM 仍在。
- 138–139.6 秒缺 16 帧 PCM，明确记录为 1.6 秒 gap 并补零；独立 MediaRecorder 录音不依赖此 PCM 路径。

共 141 个 processing，其中 139 个 final 均完成翻译/显示，1 个片尾短段为 empty，1 个重启前任务未结算。跨重启两条新字幕间隔为 **7.234 秒**，manifest 正确标记 `captionContinuity=interrupted`。严格连续性 scorer 因 gap、未结算及未提供资源时间序列而未通过；不能把恢复成功写成无损字幕或连续长测成功。

本轮另有 49 秒物理麦克风短测，受到其他浏览器音频干扰后停止。它只能说明该输入路径曾产生 ASR/翻译，**不能纳入干净声学验收**。
