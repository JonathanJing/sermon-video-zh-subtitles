# 同行每周海报格式规范 v1

2026-10-07 用户确认第三版打样的格式。本规范定义今后的海报交付，不表示既有渲染 CLI 已支持双二维码，也不改变内容审核、发布或设备验收状态。

## 画布与布局

| 项目 | 规范 |
|---|---|
| 高清图 | PNG，1200 × 1800 px，竖版 2:3 |
| 手机分享预览 | PNG，600 × 900 px，同一构图等比缩小 |
| 主色 | 深绿文字、暖白底、自然晨光主视觉 |
| 顶部 | 「同行 — 本周证道」；证道标题；系列；日期与讲员；经文范围 |
| 标题 | 通常两行；长标题允许三行或适度缩小，禁止裁切 |
| 主视觉 | 单一主题背景，不加入未经核对的证道摘录或宣传小字 |
| 底部 | 暖白入口区；左侧 iOS 下载二维码，右侧对应周次的网页版二维码；最下方完整免责声明 |
| 不展示 | 「正式播放版」类别标签、语言列表、设计框架说明、占位文字 |

已确认打样以 y=1200 为底部入口区起点，底部占 600 px；两二维码各有 288 × 288 px 白色区域。文字主要区域左右至少留 60 px，二维码保留不少于四模块的静区；最终免责声明必须完整显示，不能贴边裁切。版式适配以可读性和二维码扫描为先，不为保持固定字号而挤压文本。

App 内完整海报按比例适配；首页缩略预览与完整海报分别验证。这是展示设计约定，本 PR 不修改 SwiftUI 展示或裁切逻辑。

## 字体

对齐 iOS App 现有 SwiftUI 默认系统字体：中文由系统选择苹方（PingFang SC），英文和数字由系统字体处理。原生标题使用 `.largeTitle.bold()`，没有自行加载字体；排版使用系统字体粗体标题、常规正文，不再使用宋体标题。

AppKit 合成对应 `NSFont.systemFont(ofSize:weight:)`，标题 `.bold`，正文 `.regular`；跨设备系统回退与字形细节由 OS 决定，不承诺逐像素相同。韩语、西语与英语版也优先使用对应系统字体，并重新验证长文本；中文打样通过不等于其他语言已验收。

App Store 官方徽章内的文字和标志保持官方素材原样，不应用海报字体、重绘、改色或拉伸。

## 两个真实二维码

| 位置 | 目标与文字 |
|---|---|
| 左侧 | 同行正式 iOS App 的 App Store 下载页；下方放对应语言的官方 App Store 下载徽章 |
| 右侧 | Firebase 正式站点的精确本周网页；下方「网页版」「扫码阅读 · 收听」 |

正式 App 下载二维码固定为 `https://apps.apple.com/app/id6809255441`。每周网页二维码使用 `https://ai-for-god-sermon-audio.web.app/?week=<pageId>&contentLang=<locale>&lang=<interfaceLang>`；不能误用 Beta/Dev origin，也不能遗漏周次或语言绑定。中文为 `contentLang=zh-Hans&lang=zh`，韩语为 `ko&lang=ko`，西语为 `es&lang=es`；英语内容目标仅在实际发布后配置。未发布独立英语内容时，可生成明确标注「中文音频 · 英文对照」的英语宣传海报，网页二维码使用 `contentLang=zh-Hans&lang=en`；不得添加虚构的 `en` 内容 release 或 App announcement。

左侧二维码进入商店下载，不能宣称会直接打开本周证道。Universal Links 未在本海报规范中实现。二维码由真实编码器生成，不交给图像模型绘制。

官方徽章来源与规则：[Apple 营销规范](https://developer.apple.com/app-store/marketing/guidelines/)。保留原比例、规定留白，屏幕显示高度至少 40 px，印刷高度至少 10 mm；印刷须根据实际尺寸检查，不凭像素数声称已验证。每张海报只放一个 App Store 徽章。

## 中文免责声明

与 App 内「关于同行」原文一致，允许换行，不自行删减或改写：

> 独立个人项目，与 Mariners Church 无隶属或背书关系。
> AI 合成中文音频与整理文字仅供个人跟读参考。

源文见 [ContentView.swift](../apps/tongxing-ios/App/ContentView.swift) 的「关于同行」Section。其他语言使用 App 对应已核对的本地化文案；如果 App 文案变化，海报规范与模板同步更新。韩语／西语海报将本地化免责声明中的音频语言改为实际的韩语／西语；英语参考海报保留 Chinese audio，不能暗示英语音频已发布。

## 主视觉 prompt 与合成

每周先按 [内容 brief 与提示词流程](tongxing-weekly-poster-content-brief.zh.md) 提取核心信息和完整句证据，再展开 [可复用模板](prompts/tongxing-weekly-poster-content-template-v1.txt)。主体、环境、光线与色彩需对应当周内容，不把固定品牌风格当成固定证道主题。

本次晨光山景的完整实际生成提示词保存在 [tongxing-weekly-poster-sunrise-v1.txt](prompts/tongxing-weekly-poster-sunrise-v1.txt)。使用内置 ImageGen，仅生成无文字背景。每周主题变化时按已核对的证道内容调整场景，并记录实际使用的完整 prompt；不把希望、守护或山景当作所有周次固定的内容解释。

标题、日期、讲员、系列、经文从精确 pageId 的正式 catalog/content/release package 读取。字体、官方徽章和两个二维码由本地排版合成，不靠模型生成；当前文档 PR 未将打样脚本接入既有正式 CLI。

## 验收与证据

- 校验正式 release 状态、catalog/release/content 哈希及页面身份，不以文件夹日期猜测内容。
- 对最终高清 PNG 和手机预览 PNG 各自独立解码，必须恰好得到两个二维码且完整 URL 与目标逐字一致。
- 在浏览器核对网页版正确标题、周次、内容语言、界面语言；Apple 下载页核对 App 名与正式身份。
- 目视检查两尺寸的标题、元数据、免责声明、字体、官方徽章比例、留白与裁切。
- 保存 `poster.png`、`poster-preview.png`、实际 prompt、主视觉、官方徽章来源以及 `poster-receipt.json`；收据记录输入/输出哈希、二维码结果、机器目视检查及人工意见。
- 用户确认「格式没问题」只记录为版式确认，不把机器目视 QA 改成人工内容审核。真机扫码、印刷、网站上传与外部发送分别记录。

2026-10-04 中文双二维码第三版打样已完成：1200 × 1800 与 600 × 900 图片中两个二维码均独立解码通过；浏览器落点为《耶稣审判并保守》中文页面；下载落点经 Apple 查询与 HTTP 200 核对为同行正式 App。App 免责声明原文已核对，两尺寸已目视检查。本轮未验证纸张印刷与物理手机扫码，未上传或替换线上海报。

用户可见打样与机器收据保存在本地忽略的 `artifacts/sermon-poster/2026-10-04-dual-qr-proof-v3/`；图片不提交 Git。该路径是历史打样证据，干净克隆不含产物，不能把本规范当作可直接运行的双二维码渲染器。

## 四种语言共用主视觉

制作范围为中文（zh-Hans）、英语（en）、韩语（ko）、西语（es）。同一周只生成一张无文字主视觉，四张海报复用完全相同的图片文件及 SHA-256；分别排版标题、系列、经文、入口文字、免责声明及官方徽章。网页二维码绑定实际已发布的内容语言，iOS 下载二维码一致。主视觉一致不要求各语言的换行和字号一致。

2026-10-04 四语海报已完成两尺寸合成、双二维码解码和机器目视检查。韩语、西语标题及系列读取同语言已发布内容；英语标题为中文标题的编辑翻译，属于参考宣传素材。官方徽章使用 Apple 的 `zh-cn`、`en-us`、`ko-kr`、`es-es` 版本。生成产物和逐语言收据保存在忽略目录 `artifacts/sermon-poster/2026-10-04-four-locale/`。

本次完成四语本地合成与授权上传；既有正式渲染 CLI 仍只支持中／韩／西，四语新模板尚未接入自动生产。当前 iOS 海报匹配按**内容语言**选择；英语宣传海报不加入不存在的英语内容目标，不声称只切换 App 界面到 English 就会自动显示它。
