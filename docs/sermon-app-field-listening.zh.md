# App 现场收听与位置恢复

现场版围绕当前字幕和始终可达的播放控制组织；这是预生成中文音频的手动跟随工具，不会自动读取现场视频时间。

## 听众操作

1. 戴好耳机，核对标题和周次；在约定的证道起点按“开始播放”。
2. 中文落后时按“前进1秒”；中文抢先时按“后退1秒”。字幕、大纲和反馈中都能暂停与调节。
3. 中途加入或需要大幅定位时，打开“定位 / 精调”，输入分:秒，或拖动进度条并松开。四分之一秒与5秒调整在同一面板。
4. 误跳后按“撤销跳转”，恢复跳转前的位置与微调。普通正文不会触发跳转；全文中只有独立时间按钮可定位。
5. 切换全文后可直接阅读，按“回到当前句”找到当前段落；在其他收听视图该按钮返回当前字幕。
6. 刷新或切周回来，选择“恢复到…”；主播放键“继续上次收听”也会恢复后播放。恢复提示不会自动播放，且明确说明现场可能已继续。

“更多”保留历史周次、讲员音色、制作进度、下载、审核说明和完整反馈。主界面继续标明候选/待审状态，未将界面改进当成音频或现场同步验收。

## 保存边界

播放位置仅存在当前浏览器本地，按周次、音轨ID和音频SHA-256精确绑定，最多12条、30天。恢复包含位置和累计微调；换音频哈希不套用旧进度。起点前2秒和距结尾不足2秒不保留恢复提示，过期或无效记录忽略。浏览器阻止存储时，同页内仍可恢复，关闭页面后无法保证保留。

保存位置与匿名统计独立；关闭匿名统计不影响本地恢复。恢复不外推离开期间的时间，也不宣称已重新对齐现场。重选当前音轨不再重载；切换来源会保存旧来源的位置并停止旧音频。

## 实现与验证

前端复用现有深色/浅色变量。固定底部控件通过实际高度为正文留白，大纲、精调和反馈模态内各自提供同步的音频控制。全文段落为阅读内容，单独的时间按钮定位。进度条松开后才生效，撤销保存位置及微调。

`playback-memory.mjs` 的10项测试覆盖来源哈希、跨周、过期/坏值、开始和结束、容量限制及存储异常。相关前端/API/报表共95项Node测试通过；配音POC全套149项Python测试通过。真实浏览器已验证重选、刷新恢复、跨周恢复、正文不跳转、时间按钮跳转与撤销、大纲内暂停和微调，检查390×844、320×667及844×390横屏布局。

这些证据来自桌面Chrome的手机尺寸视口，尚不能证明iPhone/Android锁屏、耳机按钮、来电、弱网或真实现场同步通过。相关真实手机任务见本轮审核 `artifacts/sermon-dubbing/2026-09-05-field-ux-audit/audit.md`。
