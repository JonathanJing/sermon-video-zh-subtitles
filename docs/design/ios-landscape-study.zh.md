# iOS 横屏研读与收听

2026-10-28 原生设计候选。基线为 `9f32411f`；本页描述布局与交互，不代表人工确认、真机验收或发行。遵循 [Xcode-first 流程](../../apps/tongxing-ios/UI-ITERATION-WORKFLOW.zh.md)。

## 设备与布局

适用目标为 iPhone 横屏、iPad Pro 11 英寸横屏、iPad mini 横屏，以及 iPhone Duo 展开内屏横屏。沿用同行绿、语义背景与系统导航。

- 横向窗口进入页面即展开左侧「本周研读手册」，右侧保留当前字幕／全文、语言与播放入口。无需先点手册按钮。
- 使用实际窗口、安全区与播放栏扣除后的阅读区域。可用宽度至少 620 pt 时分栏；左栏为可用宽度的 45%，最小 280 pt、最大 460 pt，右栏占余下空间。以上是可调整的首版阅读比例，不按机型名称硬编码。
- 普通 iPhone 的标题采用紧凑字号层级；iPad 的左栏保持可读行长，额外空间用于右侧字幕。正文遵循 Dynamic Type，不缩小文字来塞进固定高度。
- 左侧顶部固定手册标题和目录按钮，目录以菜单跳转章节；正文、表格、图片独立滚动。右侧保持字幕自己的滚动与跟随状态。
- Duo 展开横屏继续使用系统提供的竖向工具栏与安全区；active division 出现时回退单栏，沿用原有控制区避让。展开横屏、半折与窄窗口是不同状态，不能互相代替验收。
- 转回竖屏或窗口窄于阈值后恢复原有手册入口，不改变选中讲道、音轨或播放状态。重新横屏自动展开。首版不承诺跨旋转保留左侧阅读位置。

## 内容与状态

初次进入显示目录默认讲道所对应的手册。选择历史讲道后，左栏随之切换，保留手册自带的周数与标题。内容语言继续由现有内容选择决定，不使用界面语言推断译本。

复用 `WeeklyGuideSelection` 的页面、语言、来源和发布包绑定，以及现有远端加载、取消和撤销逻辑。不得按日期猜测映射，或把最近一本手册补到无对应内容的讲道。正在加载显示进度；缺失或未通过绑定校验显示「本周研读手册尚不可用」。

左栏复用完整手册的段落、表格、列表、图示、图片放大、源链接和机器翻译披露，不以讲道大纲或合成示例替代真实内容。测试夹具只用于交互验证，并明确标注为测试内容。私人或获许可的本地手册资源继续留在被 Git 忽略的 `GuideResources/`。

## 交互验收

| 状态 → 操作 | 预期 |
| --- | --- |
| 竖屏收听 → 横屏 | 左侧自动打开对应手册，右侧保留收听内容，只有一个播放控件 |
| 左侧正文 → 目录选章节／滚动 | 左侧定位，右侧字幕位置和播放意图不被改变 |
| 正在播放 → 旋转两次 | 音轨、播放／暂停意图不变，横屏重新显示手册 |
| 当前讲道 → 选择历史讲道／内容语言 | 旧手册不回写，新选择按完整身份加载；无对应内容显示空态 |
| 大字／深色 | 两侧可滚动，目录与播放仍可操作，正文不截断 |
| Duo 展开横屏 → 半折／窄窗口 | 不跨 active division 强塞两栏，保留原有单栏入口与播放控制 |

验证结果及失败、跳过和未执行项见本轮独立运行报告。原生截图与模拟器交互不代表真机音频、Duo 折叠硬件或现场验收。
