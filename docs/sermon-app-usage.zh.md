# 听译 App 使用数据：为下一阶段开发提供依据

这个功能用于回答：每天有多少匿名浏览器使用、集中在哪些时间、哪些功能有人用、操作在哪一步停止。匿名统计默认开启，可随时关闭；保留用户此前明确关闭的选择，维护者从本机读取私有报表。

## 能回答什么

| 开发问题 | 数据与口径 |
|---|---|
| 每天多少用户使用 | 按当天随机标识去重的匿名浏览器数；同浏览器刷新或打开多个标签页可去重。多个设备可能属于同一个人，共用浏览器也可能对应多人，因此不能称为真实人数。 |
| 哪些时间有人使用 | 洛杉矶日期与小时，按事件出现的会话去重。前台页面每分钟发送一次可见心跳，表示页面可见，不证明人在操作。 |
| 哪些按钮有用 | 46 类固定动作的次数、涉及会话数，涵盖播放、暂停、前后跳转、同步微调、全文、大纲、主题、下载、反馈入口及讲员试听，并记录恢复、撤销与更多入口。 |
| 用户先后做了什么 | 每份匿名会话的秒级操作时间线，包含所在页面、周次、中文音频位置或讲员；按钮与对应键盘快捷操作归为同类。 |
| 打开后是否继续播放或下载 | 同一会话包含打开、播放点击、下载点击的逐层交集；当前报表不要求先后顺序，也不把点击当成播放/下载成功。 |
| 哪些讲员的音色有人试听 | 各讲员英文原声和中文试听的播放/暂停事件。 |

原有 `listeningSessions` 继续记录实际收听秒数与区间，`weeklyMetrics` 继续保存每周汇总；新的操作时间线使用独立 `usageSessions` 集合。操作次数与实际收听量分开解释。

## 同意、标识和采集边界

按维护者 2026-09-05 的要求，统计改为默认开启。继续使用 `sermon-anonymous-statistics-v2` 偏好：明确的 yes/no 优先；没有 v2 选择时保留 v1 的明确 no，其余首次访问默认开启。界面公开说明并提供关闭入口。

统计开启时，浏览器保存当天随机 UUID；以 `America/Los_Angeles` 日期轮换，每天覆盖旧值。服务端只保存日期与随机值的 SHA-256，不保存原始 UUID，不关联跨日个人轨迹。同源标签页通过 [Web Locks](https://www.w3.org/TR/web-locks/) 串行创建当天标识，避免同时开启时生成不同值。无法使用本地存储或 Web Locks 时，只计会话、不参与浏览器去重。跨天只能报告“浏览器日”之和，不能据此给出月度去重用户数或个人留存率。

API 凭据仍只存在当前页面内存中。每个页面、日期及重新开启统计的阶段使用独立凭据；它与赞踩/问题反馈的凭据分开，切换周次或进入音色库不会重复计算同一个页面会话。首次打开仍需成功加载公开目录，才能得到 API 允许的来源；目录加载失败时没有行为记录。

只发送允许清单中的动作和页面 ID，不发送输入文字、完整 URL、鼠标坐标、姓名、邮箱、原始 IP、User-Agent 或设备指纹。反馈正文仍由用户主动提交，通过原有私人反馈接口单独保存。托管平台常规请求日志与业务行为数据分开管理。

每批最多 30 条事件，操作后约 5 秒发送；页面隐藏、离开及每分钟也尝试发送。内存队列最多 90 条，超限丢弃数随下一批报告。每会话最多保留 500 条事件，达到后停止记录，后续行为数量未知。页面突然关闭、网络故障、浏览器拦截或关闭统计会造成缺失；任何报表都不能代表完整流量。

关闭统计立即停止采集，尝试删除当前页面已上传的行为记录及原有收听摘要；删除后的旧批次不能重新创建记录。重新开启使用新凭据。已关闭页面或过期凭据的记录不能由当前页恢复撤回，仍受保留期限约束；界面明确显示撤回失败，管理员可处理。

## 存储和一致性

数据位于项目 `ai-for-god-caption-dev`、区域 `us-west1` 的命名 Firestore 数据库 `sermon-dubbing-feedback`。新集合 `usageSessions` 的 `expiresAt` TTL 为最后更新后 30 天；TTL 异步删除。数据库禁止浏览器直接访问，只有既有专用 API 身份及获授权管理员可以访问。

`POST /api/usage` 复用来源校验，新增连续批次序号、准确内容摘要和终止撤回标记。响应丢失时，客户端重发完全相同的批次；服务端确认重放而不重复计数。序号有缺口或内容冲突返回失败，不默默丢掉中间事件。

事件时间由浏览器提供到秒，服务端检查日期、范围、周次、音轨和讲员，并另存接收时间；不能将其当成精密计时证据。所有事件必须属于同一洛杉矶日期，跨午夜建立新的页面日期会话。新目录的 `weekIds`、`voiceIds` 允许清单必须与同一构建的公开目录一致；显式兼容的旧发布仍保持反馈接口可用。

## 查看数据

管理员使用本机 ADC/IAM，仓库根目录运行：

```sh
GOOGLE_CLOUD_PROJECT=ai-for-god-caption-dev \
  node experiments/sermon-dubbing-poc/feedback-api/admin.mjs usage \
  --from 2026-09-05 --to 2026-09-05 \
  --out artifacts/sermon-dubbing/usage-report-20260905
```

`--out` 必须是尚不存在的目录，父目录需已存在。日期范围最多 31 天，报表只使用最近 30 天仍有效的记录，查询上限 20,000 份会话；达到上限会明确标记为部分结果。

输出 `index.html` 和 `summary.json`，目录权限 0700、文件 0600；浏览器直接打开本地 HTML 即可查看，无外部脚本或联网资源。导出结果不含原始浏览器哈希、令牌、数据库文档 ID 或反馈正文；会话只用报表内临时编号。报表仍是私人运营资料，不提交 Git、不发布到听众 App。

可以按一次实际周日使用周期读取报表，先观察播放入口使用率、跳转/微调集中位置、音色试听需求、下载与大纲使用率，再结合主动反馈决定开发优先级。刚上线没有数据时应显示空状态，不用测试数据冒充真实用户。

相关：[反馈与原有收听摘要](sermon-listening-feedback.zh.md)、[API 合同](../experiments/sermon-dubbing-poc/feedback-api/README.zh.md)。
