# 每周研读手册：多语言显示与上线注意事项

手册展示教会发布的原材料及其译文，按照实际讲道关联到对应的周；不再提供“大纲与默想”的入口，也不以生成的摘要代替手册正文。以下是韩语、西语与现有中文共同适用的要求；准备工作、服务器发布和客户端可用性分别核验。

## 内容与界面

- 手册正文跟随所选讲道的内容语言，界面按钮、状态和辅助功能文字跟随 App 界面语言。韩语、西语尚无对应手册时，明确显示该语言暂不可用，不静默显示中文或其他语言的正文。
- 保留原材料中的周次、标题、经文范围、段落、问题顺序、表格和对应附录；引用的原书页码用于核对。讲道别名或不同渠道只在来源身份核实后关联同一周，不按日期猜测未来讲道 ID。
- 准确标识教会原材料及来源链接、译文语言和实际审核状态。机器翻译未获人工审核时应明确说明；教会原文不等于教会官方译文，中文审核状态也不能继承给韩语或西语。
- 原文整段经文使用的英文译本与目标语言经文译本是不同的授权对象。目标语言译本和分发许可未经确认时，仅展示经文出处与范围，不凭空翻译或复制整段经文。
- 分栏、表格、图示或扫描页不能完整提取时，对照原页核对；无法重现的内容应注明缺失，不能把空标题当作完整内容。图像使用许可及无障碍替代文字分别核实。
- 支持动态字体、VoiceOver 阅读顺序和滚动；检查韩文换行、西文长标题、深浅色模式，以及与播放栏和安全区域的布局。手册正文避免被浮层遮挡，关闭后返回原讲道和播放状态。
- 网络不可用、内容不存在、校验失败及撤回分别处理：不可用时说明原因，不显示不匹配的旧语言或错误讲道内容；撤回不得绕过为本地缓存或内置内容回退。缓存与撤回按语言和讲道身份隔离。

## 制作与发布

1. 以已核验的教会英文手册为韩语和西语各自的源材料，记录源版本及哈希、页码映射、译文版本、翻译方法、审核和许可状态；不以中文译文代替原文。对表格、分栏和图示逐页检查。
2. 逐语言确认手册及插图在目标分发渠道的使用许可；经文正文另行核实译本许可。用户已确认中文、韩语和西语手册译文可在 App 公开分发，并选择韩语、西语整段经文先仅显示出处与范围；插图和具体经文译本的许可仍须分别记录。
3. 每周、每语言分别关联已核实的讲道身份，验证内容哈希和审核状态。尚无讲道身份的周仅作未绑定准备，不预先发布到错误讲道。
4. 先验证候选清单和资源，再通过现有受保护的发布流程部署；分别记录服务器回读、支持该清单的 App 版本以及目标设备实际显示结果。私有上传不等于公开启用；旧 App 不会因新增云端文件自动获得读取能力。

韩语和西语使用各自的译稿与审核记录。准备工具校验固定英文抽取稿的逐页标识及哈希、周次映射、独立机器审核记录与译稿的绑定，并在关联讲道时检查目标语言发布包和内容身份。文件哈希证明记录之间的一致性，不是模型签名，也不证明译文准确或原图表已核验；应保留实际审核请求、响应和限制，按真实审核状态展示。独立审核不通过的稿件先修订，再对修订稿重新审核。

`delivery.weekly_guide_multilingual stage` 接收英文源、逐页 v3 译稿、每周审核索引和审核记录目录；只在 `artifacts/` 下生成未绑定、未上传的私有 staging。`candidate` 额外接收已验证的完整线上快照和明确绑定文件；可通过冻结的 bundle identity evidence 核验已有内置周次，不要求先创建中文 v1 云端清单。更新、撤回须绑定旧条目哈希；每次候选处理一种语言，第二次发布前必须重新获取并验证包含第一次发布的线上快照。候选只供既有 guarded publisher 使用，不会自动部署。

2026-10-27 的检查：已提交审核的 1.26.27 只能读取随 App 内置的中文第 1–7 周；云端读取仍在草稿 PR 中。第 8–12 周中文文件已放入私有 staging，但尚未绑定未发布的讲道。状态可能变化，上线前应重新核对。
