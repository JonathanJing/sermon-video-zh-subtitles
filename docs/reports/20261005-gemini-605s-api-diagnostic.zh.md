# 605.5 秒诊断：Gemini 监督与 OpenAI API 并发回退

本轮固定窗口为 605.5 秒，沿用 r12 的冻结英文来源和三个目标语言（简中、韩语、西语）。来源机审对 `0-s125` 的异议未被覆盖；仅为链路测试使用绑定来源与机审哈希、明确标记 `simulationOnly=true`、`humanApproval=false`、`publishEligible=false` 的测试收据。下述数据均为诊断结果，不是内容批准或发布收据。

## 已观察的执行

| 阶段 | 结果 |
|---|---|
| r13，Codex CLI，高并发 L2 | 3 个语言节点约 64–66 秒后失败。部分并发调用出现 `403 Forbidden` 重连与 SSH 结果未知；没有自动重发不确定调用。Spark 的 21 个未绑定任务在本地进程退出核验后完成终态对账，但该对账不代表远端计费或响应已确认。 |
| r15，`tongxing-dev` OpenAI API | dev 项目和运行 key 经启动器加载；111 个请求有完整响应收据。三个 L2 节点均在本地校验阶段失败：Sol 复核将 `semanticReview.evidence` 返回为字符串数组，而校验器只接受单个字符串。 |
| r17，API 响应恢复 | 逐条验证请求哈希、执行身份、项目和完整响应；复用 r15 的 111 个响应，新增 80 个真实 API 请求，未重发已完成请求。三语言 L2 仍被内容或格式关口阻挡。 |
| Gemini 3.8 Flash 监督 | r13 两次、r15 一次、r17 一次成功的只读观察；没有调度、批准或释放槽位权限。r17 在韩语失败后报告 `attention_required`。 |

r15 与 r17 合计 191 个新的 OpenAI API 请求；提供方报告的输入 403,151 tokens、输出 124,930 tokens，总计 528,081 tokens。各请求完成时间的中位数分别为 7.91 秒与 8.37 秒。这些是请求耗时，包含网络与排队之外的生成过程；不能直接当作模型纯生成速度。r17 的三语言 L2 节点耗时分别约为简中 197 秒、韩语 90 秒、西语 205 秒，且均未完成，因此不能据此声称完整流程提速。

四次 Gemini 监督请求的完整请求耗时为 1.305–3.142 秒；提供方报告每次输出 100–137 tokens，对应 43.6–93.0 请求输出 tokens/秒，中位数约 80.9。该速度包括网络延迟，且监督输入较短，不能推算长篇翻译吞吐量。

与历史 Sol／Luna 监督及后续新模型并列记录时，使用[监督模型速度参考列表](../supervisor-model-speed-reference.zh.md)的任务和计时口径；这些运行不是同输入的直接速度排名。

## 内容关口与修复

已将非空的 `semanticReview.evidence` 字符串数组按原顺序合并为校验文本，同时保留原始模型响应。韩语组 `group-0018` 的初译把 `targetUtterances` 返回为结构化对象；新适配只在对象与冻结来源 ID 一一对应、`targetText` 非空时提取文本。此格式修复尚未完成第三轮真实 L2 验证。

r17 的 Sol 复核还明确拒绝了简中 `group-0018`、`group-0021`、`group-0029`，西语 `group-0021`、`group-0024`、`group-0026`、`group-0040`，以及韩语 `group-0021`。主要问题是直接经文引述仍缺少已核验的固定版本措辞或引用证据，以及来源 `0-u076` 中 “You're filled” 的语义不明。这些是内容疑点，不能靠 JSON 兼容处理或监督器能力放行。须先核实来源音频和经文规则，再以新修订重跑受影响组的翻译、独立复核与语言检查。

本轮未生成可入选的 L2 候选，因此大纲、默想、L3 本地配音、L4 页面和 iOS Beta 发布均未执行。Spark 排他会话已关闭，原有四项服务与模型健康检查恢复；抢占前的旧 `queue.json` 快照及中断观察收据保存在 Spark 私有状态目录。原调度器服务已启动，两个中断前的定时任务是否从已有产物恢复尚未核验。API 共享资源账本全部 193 项预留均为 `released`。

本地证据位于忽略目录 `artifacts/next-concurrency-605s-20261005-r13-gemini/`、`r15-gemini-openai/`、`r17-gemini-openai-recovery/` 对应的完整路径下。原始 API 响应、逐节点终态、Gemini 用量与时间收据均保留在各轮目录，不纳入 Git。
