# 逐句优先代理实验首跑：2026-10-18 证道片段，中文

日期：2026-10-21 至 10-22（UTC）。实验线：[experiments/sentence-first-agent](../../experiments/sentence-first-agent/AGENTS.md)。标签 `experiment_only`，不是正式交付，没有发布。音频与视频只留在本机忽略的 `artifacts/` 里。

## 跑了什么

| 项 | 值 |
|---|---|
| 来源 | 2026-10-18 证道（resi 15030286，讲员 Steve Bang Lee，启示录 10:8–11） |
| 片段 | 锚点单元 127–214，88 句，424.67 s；与 2026-10-20 正式 scroll 片段同范围 |
| 词时间与分句 | 复用 2026-10-17 Layer 1 的 MFA 结果和 `clause_stable_v2` 单元，未改边界 |

| 声音 | steve_bang_lee 按讲员 SFT checkpoint（Qwen3-TTS 1.7B），zh-Hans 能力已人审 |

| 回转写 | Spark，Qwen3-ASR-0.6B，batch 8 |

用户请求里的来源、窗口与讲员是未填的占位符。代理改用上表这个已有完整 Layer 1 证据的片段，好与正式输出对照。

## 结果

| 指标 | 值 |
|---|---|
| 合成成功 | 88 / 88 |
| TTS 墙钟（不含模型加载） | 284.0 s，约 1.37 倍实时 |
| 配音总长 / 原声讲话总长 | 387.8 s / 343.6 s = 1.13 |
| 合并音轨长度 | 419.11 s |
| 最大落后 | 6.98 s（s0043） |
| 落后超过 8 s 的句子 | 0 |
| 复核修订 | 1 句（s0007 删去英文没有的“经文”） |
| ASR 平均相似度 | 0.997；低于 0.88 的 0 句 |

ASR 不完全一致的 4 句里，3 句是同音字写法（它/他、再/在、哪/呐）。另一句是人名：以西结被识别成以希杰，原因可能在 ASR，也可能在 TTS 读音，需要人听。

落后集中在 s0040–s0060。这一段短句密集，原声句后停顿短，配音逐句顺延，最高落后接近 7 s，之后被较长的停顿吸收。粗估会超预算的 4 句实测都没有把落后推过 8 s，所以这一遍没有做口播精简。

## 人工听审

2026-10-22 用户听了发给用户的 640px 预览视频，结论为**通过**：以西结的读音、s0040–s0060 区段 5–7 s 的落后都可以接受。这次听审只针对实验产物，不构成任何正式 Layer 2 或 Layer 3 的人审收据。

## 没有验证的部分

- 没有与 2026-10-20 正式 zh-Hans 译文做逐句比较。
- 韩语、西语按用户要求在 2026-10-22 中途停止，保持原样：两语的译文与复核已完成；韩语 88 句已在 Spark 上合成，但没有拉回、合并或听审，回转写停在 16/88；西语没有开始合成。
- ASR 抽查不是听审，相似度只用于定位要听的句子。

## 对路径的结论

从已有 Layer 1 词时间出发，代理一个会话就能完成拆句、切片、逐句译审、口播规格、本地配音、合并与回转写，不需要 controller、外部翻译 API 或哈希绑定。片段级的时间预算在 batch 1 下成立。下一步取决于人工听感，以及是否要扩到三语或整篇。

运行中发现两处操作问题，已写进实验步骤：Spark 宿主 Python 没有 `qwen_tts`，须在固定镜像里挂载 voice site-packages 运行；用 `nohup … &` 从 SSH 启动会把会话挂住。
