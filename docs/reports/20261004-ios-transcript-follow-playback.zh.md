# iOS 全文跟随播放与时间入口

用户要求：底部左侧播放时间在「字幕全文」时可返回当前字幕，全文可随播放移动，并评估移动效果及是否独立滚动组件。

## 交互决定

- 全文默认准备跟随；开始／恢复播放时定位当前句，字幕换句时移动一次。采用 0.25 秒 easeInOut；减少动态效果时不加动画，不逐字滚动或按每次进度回调移动。
- 手动纵向拖动进入自由阅读，播放仍继续，字幕换句不抢走阅读位置。
- 点播放时间或顶部当前句回到音频对应句并恢复跟随；暂停时点它仍暂停，不 seek。进入另一周次、音轨、页或语言时重置跟随意图。
- 顶部当前句使用实心／空心图标及无障碍状态表示跟随／自由阅读；播放时间保持原进度值，并在全文中提供至少 44 pt 点击区。

本轮保留现有单一 `listening-scroll` 与两类懒加载全文列表。不要把纵向 ScrollView 再嵌入另一个纵向 ScrollView；其手势和高度边界会更难保持一致。后续如果要让标题、语言和模式选择固定在顶部，可改为「固定头部 + 独立正文滚动组件 + 固定播放栏」，届时需要小屏、大字、横屏及返回行为的独立验收。本轮没有完成此布局拆分。
