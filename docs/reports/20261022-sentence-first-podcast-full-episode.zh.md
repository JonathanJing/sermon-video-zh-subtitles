# 逐句优先代理实验：播客整期三语双声配音

日期：2026-10-22（UTC）。实验线：[experiments/sentence-first-agent](../../experiments/sentence-first-agent/AGENTS.md)。标签 `experiment_only`，不是正式交付，没有发布；正式播客生产由另一个代理负责，本实验没有写它的目录。音频只留在本机忽略的 `artifacts/` 里。

## 跑了什么

| 项 | 值 |
|---|---|
| 来源 | 播客 If I Had More Time，Jesus sends and resurrects His own（episode.mkv，40 分钟） |
| 句子 | 746 个 Layer 2 锚点单元，批准窗口 5.5–2406 s |
| 说话人 | 2026-10-20 的 VibeVoice 结果与用户确认的映射（0 = Steve Bang Lee，1 = John Thomas），按转写逐词对齐投票；Steve 332 句，John 414 句 |
| 声音 | 两位讲员各自的 Qwen3-TTS SFT checkpoint；John 于本日写入 Speaker Voice Registry，授权与人工听审依据为用户在对话中的两句话 |
| 中文译文 | 直接用人工批准的 Layer 2 候选 |
| 韩语、西语译文 | 8 个子代理并行，每语 4 段，先译后独立复核；韩语 14 句、西语 25 句在复核中改过 |
| 合成 | Spark GB10，bf16，batch 1，seed 7；每次一个登记在独占会话里的容器 |
| 回转写 | Spark，Qwen3-ASR-0.6B，batch 8 |

## 结果

| 指标 | zh-Hans | ko | es |
|---|---|---|---|
| 合成成功 | 746 / 746 | 746 / 746 | 746 / 746 |
| 配音总长 / 英文讲话总长 | 1.28 | 1.26 | 1.30 |
| 合并音轨 | 51.4 min | 50.7 min | 52.3 min |
| 最大落后 | 682 s | 639 s | 735 s |
| 落后超过 8 s 的句子 | 740 | 742 | 740 |
| 回转写平均相似度 | 0.986 | 0.979 | 0.962（忽略重音 0.990） |
| TTS 速度（不含加载） | 约 1.35 倍实时 | 1.36 | 1.38 |

**同步不成立。** 7 分钟讲道片段能把落后压在 7 s 以内，是因为讲员停顿多；双人对谈几乎没有停顿，按自然语速配音每句只多一点，整期累积到 10 分钟以上。按已配音频重新排程估算：配音整体短 25%、句间不留空时，最大落后约 7.7 s，没有句子超过 8 s；只短 20% 时仍有 56 句超过 8 s。

**回转写的低分大多是识别器问题。** 中文多为把“千禧年”听成“迁徙年”；韩语多为英文专名的韩文读法；西语多为 Sí 被写成 si。需要人听的少数句子：中文 s0738“阿们”、s0028；韩语 s0058、s0160“그럼요”；西语 s0314、s0607、s0304、s0214。

## 运行中遇到的问题与处理

| 问题 | 处理 |
|---|---|
| 另一个代理的独占会话自 04:08Z 起闲置未关，且它 10-21 的收尾被本实验的测试容器打断 | 用户授权后关闭该会话（服务恢复），本会话另开独占；此后每个容器都作为登记任务运行 |
| 说话人记录从未接进本期生产（`speaker-turns.json` 全为占位） | 用户确认的 VibeVoice 结果按时间、再按逐词对齐映射到现行 746 句；23 句短附和因此换了讲员，zh 已按新分配重配 |
| 带 `--rm` 的容器退出即被删除，会话工具每次检查已绑定容器都失败 | 用户同意后备份并手工去掉那个已删除的容器 ID，再正常结束任务；之后登记容器不再用 `--rm` |
| 会话工具读不到 root 容器进程，运行中的任务旁不能再开任务 | 三语排队顺序跑 |
| 一次 SSH 启动调用超时导致本机脚本退出 | 容器已在跑，手工绑定后续跑；脚本改为超时不退出 |

## 没有验证的部分

- 没有人听过三语整轨。
- 没有与另一个代理的正式播客输出比较。
- 18 句说话人一致度低于 0.8，没有逐句人工核对。

## 结论

逐句优先路径可以在一个会话里把双人播客三语配完：说话人、译文、两种声音、回转写都走通，总计算约 2 小时。跟原视频同步需要口播精简约四分之一，或者把配音作为不随视频同步的独立音轨；哪一种由用户决定。
