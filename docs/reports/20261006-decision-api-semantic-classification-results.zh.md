## 请求、恢复与指标

使用[语义runner](../../scripts/experiments/decision_semantic_eval.py)及原隔离[dispatch／ledger](../../scripts/experiments/decision_api_weekly_ab.py)。第三轮authority冻结新代码／案例／payload身份，封存第二轮并唯一绑定第三轮，保留全部历史估算／预留。每次派发前写intent与预算；120秒超时，无隐式重试；未知结果停止并保留待对账状态。只统计identity、payload及ledger receipt hash匹配的原始收据，resume不重发已完成项。

为容纳真实15句批次，本runner显式采用65536的保守输入token规划上界（按bytes保守估算），最大实际预检bound57573；原runner默认上界与生产守卫未修改。每组两臂交错、逐环节执行，source-support组仅按上界拆批，不截断来源片段。冷启动计入网络调用面板；一次观测、无重复时延面板。

真实输入仅报告A/B标签分歧，不能称准确率。构造输入仅报告作者标签符合率并列出错误；不代替真实来源的召回率、质量非劣或人审收益。请求失败／未完成单列，不从全部请求成功率分母删除。完整审核证据、fallback链、人审active分钟、返工和整周耗时仍未实测，不据此宣布生产替换。

## 本轮接入判断

六类任务都能运行成有限选项分类，并在66条构造案例上得到预期标签。可研究的用途是大纲来源预筛、反馈归类、模糊修复建议；后三者不能据此自动获得人审时间或费用节省。E03／E08仍缺真实任务池，E06仍缺真实错误和人工计时。

E01已有真实拒绝通过分歧，E02存在来源不清与译错分类边界，E04存在文本／同音／实际音频的证据边界，当前不直接替换审核或听审。翻译修稿、机器书面证据、来源裁定、人审与执行门仍由原链完成；没有生产策略或候选准入变化。

下一项质量实验需要独立人工标注及新的留出材料；针对上述实际分歧先固定rubric，避免继续只增加容易构造题。真正收益须测省掉的原模型工作、人审active分钟和返工。本轮达到分类能力探索的既定范围，未为用完$20而继续调用。
