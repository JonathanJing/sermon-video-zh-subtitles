## 错误与修复

1. **原目录命中故障**：紧凑横屏菜单 y=31.33–75.33，位于导航 AX bounds y=24–78 内，`isHittable=false`。仅把标题栏改成 safeAreaBar 不足；左栏消费当前容器报告的顶部安全区后，菜单 y=58.67–102.67，正常点击成功。无固定机型／像素偏移，右侧滚动区域不变。
2. **iPad 重复留白**：普通高度系统已预留顶部空间，统一补偿又产生明显空白。限制额外顶部避让为 compact vertical size class；mini 同条件复验确认多余空白消失。Duo 常规高度保留系统侧栏和原安全区。
3. **测试几何假设过强**：系统导航栏 AX 外接矩形不等同于实际触摸拦截区域。独立审核认可移除“两个完整 AX 矩形不得相交”的附加断言；保留 frame 记录、可命中、正常点击后的章节出现和正文定位。
4. **短样本自然播放结束**：播放器在菜单操作中仍推进；XCTest 等待 idle 约 29 秒，让 36 秒夹具播完。测试先验证旋转后的时间推进及播放状态，再暂停检查二次目录操作的稳定位置。播放中操作菜单由真实长音频独立验证，不宣称这个 XCTest 覆盖该路径。
