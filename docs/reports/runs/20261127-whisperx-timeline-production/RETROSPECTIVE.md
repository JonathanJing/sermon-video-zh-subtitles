## 5. 可以改进的地方

- **质量**：唯一阻塞是人工听审。听审页只覆盖 20 个最大位移单元；正式批准前建议至少抽查窗口首尾、专名、数字、否定和掌声边界。
- **流程**：`sfa.py start --timeline-package` 已能拒绝候选包，但候选生成仍是单独命令；连续两期通过后可考虑把“父包 → 候选 → 听审提醒”并入 `sfa.py` 的 preflight。
- **运行环境**：WhisperX 需要独立 Python 3.11 runtime；生产 `.venv` 不应安装 torch。应把 runtime 路径写进 runbook/环境预检，而不是依赖 `artifacts/` 里的实验 runtime。
- **精度**：本工具用父时间轴分块；若父单元边界严重错误（>1 秒），精确分块可能切到词。当前 2026-11-08 数据 123/123 成功；下一期应继续监控 `chunk_exact` 失败率。
- **报告**：本轮仍是手写运行报告；可把工具输出改成导出器认识的 `outcome.json`/`timings.tsv`，减少手工脱敏。
