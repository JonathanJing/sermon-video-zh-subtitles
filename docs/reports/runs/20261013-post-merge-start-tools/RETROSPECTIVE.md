## 错误

1. **韩语章号读法退化。**
   - 现象：`그렇기 때문에 8장을 보면`没有转成`팔장`，TTS 读成`여덟 장`。
   - 原因：88230743 给规则 v3 加的守卫，只在白名单引导语后转换单独章号；`때문에`不在名单里。
   - 处理：#393 把不会计数物品的连接词和副词加入名单，并加了回归测试。
   - 后果：#393 改变机器质检实现哈希，本轮放行证明不能沿用；合并后三语质检需要重签。
2. **中文译文意思偏移**（内容问题）：按规则开新修订 r2，没有对同一候选重跑质检。
3. **第一次 `spark_exclusive_session.py begin` 失败**，1.5 分钟后再开成功。错误输出被第二次覆盖，原因没留下。续跑脚本已改为分别保存每次的输出。
4. **执行脚本把预算和渲染逻辑写在同一个循环里，韩语失败后西语没开始。** 已手动续跑。
5. **渲染步骤退出码为 1**，与上一轮相同（原始渲染的初筛标记）。压缩和正式初筛照常完成。
