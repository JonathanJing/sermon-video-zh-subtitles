## 错误与处理

1. 第一次全站哈希通过，但浏览器退回上周：content v3 的可选 sourceVideoUrl 被 reader 无条件验证。修复缺省 URL 处理和无链接时的 UI，99 项相关测试通过。提交 `03982120`。
2. 旧声纹 index 实际截取整场 0–2131 秒，而批准窗口为 1749–3880 秒。用绑定的 lossless FLAC 重建窗口内索引，没有修改源批准。旧索引在后两段样本不能匹配，证实不能只改元数据数字。
3. fingerprint UI 仍以 0.1 秒阈值拒绝中文/西语自然末句尾差，而 builder 已允许原窗口路径 -0.1 < drift < 1.1 秒。统一该路径阈值，保留历史无窗口容差与身份约束，84 项定向测试通过。提交 `7d9fb729`。
4. GCS SDK 首次上传在发送首块前拒绝 checksum=auto；保留失败证据，以该版本支持的 md5 参数成功上传不可变对象。
5. 扩大检查发现 12 个历史音色示例对 Range 返回完整 200，而非 206。文件字节全部正确，本周正式音轨 Range 不受影响。未修改历史音色资源，单独记录该限制。
