# 系列各篇标题表

本文件登记已由用户审定的各篇证道标题译名，供每周元数据批准、页面 `title` 字段和海报使用。系列名仍以[系列名称表](series-terminology.zh.md)为准；本表不改动那张表，也不进入冻结翻译政策的哈希。译名是本项目采用的译名，不是 Mariners Church 官方译名。

## 使用方式

- 某周来源确认后，按英文原标题和经文在本表找到该篇；英文标题与官方页面一致时，直接采用本表三语标题作为已批准的本篇标题，不再单独请用户批准标题。讲员、日期、经文等其他元数据仍按[每周发布](tongxing-weekly-release.zh.md)流程核对。
- 页面名称仍按「系列名 · 本篇标题」组合，例如「启示录：耶稣带来的安慰与盼望 · 耶稣得胜」。
- 实际英文标题、经文或排期与本表不符时，不套用本表，按原流程向用户确认，并在这里更新。
- 本表只是生产参考，没有接入任何生产程序；登记在这里不证明某个运行已经读取它。
