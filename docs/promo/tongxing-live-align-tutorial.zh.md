# 同行听音定位教学短片：分镜与录制方案

目的：教会众在礼拜现场用同行 iOS App 的"听现场并对齐"（听音定位），在 45 秒内学会三件事：从哪里点、听的时候怎么拿手机、没对上怎么办。它是使用教学，不是功能宣传；画面全部用模拟器里真实 App 的录屏，不画示意界面。

- 时长：不超过 45 秒。主版本竖屏 1080×1920（微信、视频号、群里转发）；另出 16:9 1920×1080 供堂内大屏，手机画面放右侧，字幕放左侧。
- 声音：中文旁白 + 轻音乐。模拟器录屏不带声音，旁白后期配；可在"对上了"镜头混入 2–3 秒已人工审阅的中文配音。
- 字幕：每镜一行大字，旁白逐句对应；界面里的按钮名用引号原样引用，不改写。
- 画面标注：右上角全程小字"模拟器演示 · 非现场录制"。

## 教学要点

看完要记住的五件事，分镜按这个顺序讲：

1. 进场前打开本周证道，选好中文，戴上耳机。
2. 入口在底部播放条的放大镜（"定位"）里，按钮叫"听现场并对齐"；第一次要允许麦克风。
3. 听的 7 到 15 秒里：手机拿在手上、别挡麦克风、别锁屏、App 留在前台。中文配音这时会暂停。
4. 对上后显示"已对齐至 12:34。"，中文从讲员正在讲的那句继续。
5. 没对上：点"重试对齐"，或"按英文找位置"输入刚听到的英文词；还差一点用"定位 / 精调"的前进、后退 5 秒。

## 录制方法：在模拟器里跑真实流程

录屏来自当前源码的正式 channel 构建，页面用线上正式页，匹配用真实麦克风，不用测试夹具。

1. 构建并启动当前源码（`Tongxing` scheme 是 production channel，首页显示"已发布页面"而不是"Dev 内容"）。从仓库根目录：

   ```sh
   apps/tongxing-ios/scripts/ios.sh build
   apps/tongxing-ios/scripts/ios.sh launch --simulator "$TONGXING_SIMULATOR_UDID"
   ```

   UDID 从 `xcrun simctl list devices booted` 取当前启动的 iPhone；录制用 iPhone 17 Pro 尺寸（402×874 pt，录屏 1206×2622）。
2. 模拟器准备：Simulator 菜单 I/O → Audio Input 选 Mac 的麦克风；外观浅色；状态栏固定：`xcrun simctl status_bar <UDID> override --time 9:41 --batteryLevel 100 --wifiBars 3`。App 右上角语言菜单选"简体中文"，关掉"本周更新"卡片。
3. 页面准备：打开 2026-10-25 页，选"简体中文"，等播放条显示就绪，按一次播放再暂停在 `00:00` 附近，这样镜头 5 的时间跳变明显。
4. 英文原声：在 Mac 上用 QuickTime 或浏览器播放页面绑定的来源，从证道中段开始，音量中等，离 Mac 麦克风约 1 米；正式录制前先试对一次，确认"已对齐至"出现。本机的完整崇拜录制哈希与绑定来源不同，试对不成就改用 YouTube 来源。
5. 录屏：每个镜头单独一条，Ctrl-C 结束。

   ```sh
   xcrun simctl io "$TONGXING_SIMULATOR_UDID" recordVideo --codec h264 --mask black artifacts/tongxing-ios/$(date +%F)/live-align-tutorial/take-03-entry.mp4
   ```

   镜头 4–5 连续录一条；镜头 6 在 Mac 静音时再录一条，等 15 秒出现"听音对齐未完成"。录屏没有声音，Mac 上播放的讲道原声不会进片。
6. 后期：ffmpeg 裁剪拼接；手机画面缩放到约 1600 px 高居中，上下留白放标题和字幕；字幕用 PingFang 或品牌字体；右上角加"模拟器演示 · 非现场录制"。套设备外框可用 [Frames](../../apps/tongxing-ios/FRAMES.zh.md)，本机尚未安装，不是必需。
7. 原始录屏、截图和 ffmpeg 命令留在 `artifacts/`，不入 Git；成片放到 Dev Hosting 的 demos 目录或直接发群，按用户指示。
