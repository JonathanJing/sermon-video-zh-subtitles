# 同行 App 介绍短片：分镜与旁白

目的：让不懂英语、但渴慕信仰生活的会众知道，在同一个礼拜堂里，可以用自己的语言跟上同一篇讲道、同一场敬拜。

- 时长：约 66 秒。主版本 16:9（1920×1080，用于堂内大屏），另出竖屏 1080×1920（用于微信、视频号转发）。
- 风格：开场和结尾用 lemo-opuscar 的 **Stained Glass**（彩色玻璃）；中段用 **Living Screencast**（界面演示），调成暖色，配色取自同行品牌的深绿和米白。
- 真实画面：中段直接插入 Eric Geiger 60 秒演示的真实片段。lemo 负责插画和界面动画，真实片段用 ffmpeg 拼接，不交给 lemo 重绘。

## 片尾免责小字

> 讲道片段：Mariners Church 2026-09-20 周末聚会。本项目为个人项目，与 Mariners Church 没有隶属或合作关系。译文与配音由 AI 生成，并标注审阅状态。"效果示意"镜头为目标效果，不代表已完成现场验收。

## 对外发布前要确认

1. **讲员的影像和声音。** 中文、韩语、西语配音是用 Eric Geiger 本人声音训练的 AI 合成声音。现有演示放在 Dev 预览页，并标注了来源。宣传片会被转发到更大范围，公开传播前应先取得 Mariners Church 或讲员本人的同意。还没取得同意时，只做内部分享。
2. **不要暗示官方合作。** 片中不用 Mariners 的标志或名称作背书，名称只出现在片尾来源说明里。
3. **能力说明要如实。** 已经实现的：讲道页面、多语字幕、AI 配音、网页"定位"。还没验收的：堂内实时跟听、设备播放、现场效果。后者在片中只用"效果示意"呈现。
4. 选用 Eric 的片段，而不是 Steve 的，是因为 Eric 片段的译文经过人工审阅；Steve 片段的译文只经过机器审阅。

## 制作步骤

1. 安装 lemo-opuscar：`claude plugin marketplace add lemomo-ai/lemo-opuscar`，然后 `claude plugin install lemo-opuscar@lemolab`。
2. 用 `/lemo-opuscar` 生成镜头 1–4、7–9。输入本分镜，选 Stained Glass + Living Screencast，并提供上表中的截图和品牌图。先审关键帧，再出完整片。
3. 用 ffmpeg 从演示片段截出镜头 5、6，和 lemo 的输出按时间轴拼接。混入旁白和音乐，最后加片尾小字。
4. 输出 16:9 和竖屏两个版本。
