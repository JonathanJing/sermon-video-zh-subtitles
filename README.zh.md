# 同行：帮助中文会众跟上英文证道

[English](README.md) · [收听与阅读](https://ai-for-god-sermon-audio.web.app/) · [MIT License](LICENSE)

同行是一个个人开源项目，希望让使用中文的会众更容易听懂英文证道，也能在聚会前后阅读、重听和讨论。预制内容的生产已扩展到韩语和西班牙语；每周实际提供哪些语言，以该周已经审核并发布的内容为准。

从源视频可用到下一场证道开始，通常只有约 10–12 小时。我们需要在这一晚完成文字、配音、试听与交付，也需要留出修正问题的时间。[每周制作复盘](docs/blog/sermon-production-workflow-lessons.zh.md)记录了这条流程的挑战和正在改进的方案。

这是独立的个人项目，与 Mariners Church 无隶属、背书或运营关系。使用公开或已获授权的媒体；生成的翻译、配音和说明须保留来源与审核状态。

## 三种使用方式

### 1. 收听已经准备好的证道

针对确认过的源视频，先准备译文、配音、字幕和大纲。使用者可以按周选择内容，边听边看字幕，也可以下载音频，在聚会后重听。

预制配音用于跟随**同一场录制**。讲员参考声音的使用须有授权，音频仍是生成内容；内容审核与实际播放效果分别检查。

[打开听译 App](https://ai-for-god-sermon-audio.web.app/) · [同行 iOS 客户端说明](apps/tongxing-ios/README.zh.md)

### 2. 阅读双语资料

从公开或获授权的视频准备中英对照阅读稿，以及中文证道同行大纲。适合提前预习、聚会后回顾和小组讨论，也可作为听译不便时的阅读材料。

每次制作都要确认来源、证道范围和文字，随后审核 PDF。历史示例和生产方法见[双 PDF 工作流](docs/stable-post-live-reading-pdf-workflow.zh.md)。

### 3. 跟随本场现场讲话

当讲员正在现场重新讲述时，实时字幕依据**本场正在说的话**生成，在操作页和观看页显示中文，帮助会众跟上当前内容。

这条路径仍需要验证真实收音、翻译质量、手机显示和场地效果。操作说明见[周日字幕指南](docs/sunday-live-operations-whitepaper.zh.md)；[准备本场操作页](docs/sunday-live-agent-runbook.zh.md)会先停在待机。

## 为什么同一篇信息不等于同一场录制

周六与周日可能围绕同一主题，但措辞、顺序、例子和现场补充都可能不同。预制音轨与字幕的时间安排只适用于经过确认的那场录制，不能直接套到另一场现场讲述。

提前准备的资料可以帮助了解背景、术语和经文，却不能代替本场原声。这个区别决定了我们何时使用预制听译，何时使用实时字幕。

## 每周交付给使用者什么

| 交付物 | 用途 |
|---|---|
| 按周收听页面 | 选择已经发布的内容与语言，收听并阅读字幕、大纲 |
| 配音与随声字幕 | 跟随确认过的源视频，或在聚会后重听 |
| 中英阅读 PDF 与中文大纲 | 预习、回顾与讨论 |
| 本场字幕观看页 | 跟随当前现场讲话；使用前需要相应场地验证 |
| 每周分享海报 | 提供准确指向该周页面的二维码；发送和分享另按用户安排 |

以上是各条路径的交付物，并非每周所有功能都自动齐备。源视频、完整音频和制作中的资料保存在 Git 之外。

## 怎样判断内容已经准备好

我们分别检查源内容是否完整、翻译是否覆盖原意、配音是否自然，以及字幕能否跟上讲话。程序检查和模型复核之外，还需要相应的人工文字审核与试听。

页面发布成功、文件可以播放，说明对应交付检查通过；实际手机播放和聚会现场效果需要各自验证。历史制作记录中也保留了试听通过后现场仍暴露问题的情况，避免把一次通过当成所有场景都已验证。
