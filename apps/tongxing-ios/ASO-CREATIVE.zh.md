# App Store 创意素材改进计划（Creative Assets / CPP）

> 背景：2026-10 Apple 更新 App Store Connect，搜索结果可展示专属 Creative Assets（图片/视频），
> 配合 CPP（Custom Product Pages）按搜索关键词定制截图与素材；素材在 Asset Library 独立送审，
> 通过后已上架 App 无需发新版即可替换。本文档是设计先行稿：先定策略与 shot list，再拍摄制作，
> 最后由 Jonathan 在 App Store Connect 提交。

## 1. 这次更新改变了什么

| 以前 | 现在 |
| --- | --- |
| 搜索结果展示的图 = 产品页默认截图，全关键词同一套 | 可为每个关键词/CPP 指定专属首图（Creative Asset），搜索意图不同、看到的图不同 |
| 换截图要跟着发版走 | 素材库独立审核，通过后线上 App 直接换图，无需提交新 binary |
| 截图优化只能凭感觉 | 可以按关键词分组做意向匹配，等同于搜索广告的创意分组能力 |

一句话：**搜索结果页的点进率，第一次变成了可以按关键词精细运营的指标。**

## 2. 对同行的意义

同行的用户按搜索意图天然分成三群，之前他们看到的是同一套截图：

1. **中文找讲道资源**：搜"讲道""中文圣经""查经"——关心"有没有中文""准不准"。
2. **双语/英文用户**：搜 "sermon""bilingual subtitles""church live"——关心英文原声体验。
3. **场景型**：搜"离线听道""开车听""精听英语"——关心离线、后台、学习功能。

现在可以给每群一个 CPP + 专属搜索展示图，点进来的用户看到的正是他搜的东西。

## 3. 截图改进：shot list（按叙事顺序，共 7 张）

原则：前 3 张决定 80% 的点进/下载；每张一张大字标题（中文为主、英文为辅），
字号保证在搜索结果小图里能看清；深色/浅色与各尺寸（6.9"、6.5"、iPad）保持同一叙事顺序。

| # | 画面 | 大字标题 | 目的 | 对应关键词群 |
| --- | --- | --- | --- | --- |
| 1 | 主界面播放中，中英双语字幕占视觉中心 | 英语讲道 · 实时中文双语字幕 | 一句话讲清价值 | 全部（默认 CPP） |
| 2 | 字幕行特写 + 当前高亮行 | 听不懂的那句，有中文 | 打消"听不懂"的顾虑 | 中文群 |
| 3 | 对齐成功态（"已定位 12:34"） | 打开就对上，不用拖进度条 | 展示核心差异化 | 中文群/场景群 |
| 4 | 大纲页（OutlineSheet） | 一篇讲道，一张大纲 | 学习/复习价值 | 场景群 |
| 5 | 精听页（PrecisionSheet） | 逐句精听，练英语 | 扩展到英语学习人群 | 双语群/场景群 |
| 6 | 锁屏实时活动 / 后台播放 | 锁屏也能跟，息屏接着听 | 离线/通勤场景 | 场景群 |
| 7 | 极简三步上手（选讲道→播放→字幕出现） | 3 步开始，无需注册 | 降低下载心理门槛 | 全部 |

**不要拍的**：纯设置页、无文案的干 UI 截图、字小到看不清的密集列表页。
这些放在第 4 张之后可以，绝不做首图。

## 4. CPP + Creative Assets 策略

建 3 个 CPP（默认页 + 2 个定制页起步，跑起来再加）：

- **CPP-A「中文讲道」**：关键词"讲道 中文圣经 双语字幕 查经"。
  搜索展示图 = shot list 第 2 张（字幕特写）。产品页截图顺序：1→2→3→4→7。
- **CPP-B「Sermon EN」**：关键词 "sermon bilingual subtitles church live translation"。
  搜索展示图 = 英文界面的第 1 张变体（英文大字标题 "Live Chinese subtitles for English sermons"）。
  产品页截图顺序：1(EN)→5→3→6→7。
- **CPP-C「离线精听」**：关键词"离线听道 开车 精听英语"。
  搜索展示图 = 第 6 张（锁屏实时活动）。产品页截图顺序：1→6→5→4→7。

素材库流程：每张 Creative Asset 单独送审；通过后线上直接替换，
截图迭代不再占用发版窗口（与 RELEASE-READINESS.zh.md 的发版流程解耦）。

## 5. 提交文案改进（草稿，可直接用）

- **副标题（30 字）**：英语讲道实时中文双语字幕，离线可听。
- **关键词（100 字符，用满，逗号分隔，不重复标题已有词）**：
  讲道,查经,圣经,双语字幕,听道,离线,精听,sermon,bible,chinese,subtitle,church
- **描述前 3 行**（"阅读更多"折叠线之上，决定去留）：
  > 听英语讲道，不再靠猜。打开同行，中文双语字幕实时跟上；
  > 打开就自动对上进度，不用拖进度条；下载后离线、锁屏都能听。
- **宣传文本**（随时可改，不用送审）：写当前版本亮点，
  例："新版：打开 7 秒自动对上讲道进度"。
- **预览视频（15–30 秒）**：只拍一个瞬间——点开讲道→字幕"对上"的那一刻。
  不要功能巡游，用户 3 秒内要看到"字幕出现了"。

## 8. App Store Connect API 4.5.1（2026-10-06）与自动化

- Apple 于 2026-10-06 发布 App Store Connect API 4.5.1（[release](https://developer.apple.com/news/releases/?id=10062026a)）。
- 按 Apple"网页端先上、API 跟上"的惯例，预计补齐 Creative Assets / Asset Library 的程序化接口：
  批量上传素材、查询送审状态、替换线上素材。具体 endpoint 待官方文档更新后确认
  （⚠️ 本节为基于发布时间点的推断，以 Apple 正式文档为准）。
- 意义：截图与素材迭代可以脚本化（上传→送审→替换全链路），不再依赖手工点 Connect；
  与第 4 节"素材迭代不占用发版窗口"叠加后，创意运营完全解耦。
- 4.5 系列其他已知变化（与本计划无关，记录备查）：app-tag `territories` 相关接口废弃；
  "最后兼容版本"的 `downloadable` 属性转正为公开 API。
