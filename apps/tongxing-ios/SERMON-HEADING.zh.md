# 证道标题信息层级

日期：2026-10-01。开发候选分支 `codex/ios-screen-density`，基线 `c4c3453`；本轮尚未上传 TestFlight，不改变 Beta `1.2.0 (47)` 的冻结源码或分发记录。

## 显示规则

主收听页和“选择证道”列表共用 `SermonHeadingView`，按以下顺序显示：

```text
耶稣配得
启示录：耶稣带来的安慰与盼望
2026-09-27 · Eric Geiger
```

标题加粗，主页面使用动态大标题，列表使用 headline。系列独立一行、使用较小的次要文字；用换行分隔标题和系列，不再把长系列与版本说明拼入大标题。日期与讲员使用中点「·」连接；宽度不足时完整字段分行，去掉中点，避免孤立分隔符。缺少系列或讲员时省略该字段，不补猜，不留下多余分隔符。内容不截断，支持自然换行。

旧目录仅剥离明确声明的系列后缀，以及已知的「｜正式播放版」「｜YouTube 版」后缀；版本仍以小字显示，保留来源选择的区别。普通题目中的中点、冒号与未知竖线文字原样保留。原始目录标题和来源身份不变。日期原来位于标题上方的旧周次也改为放在系列下面，经文引用独立保留。

列表第二行不再用语言列表替代讲员；可用内容语言仍从既有语言选择入口查看。无障碍字号下证道弹层继承主页面字号并默认展开为大弹层。

## 元数据与播放边界

既有 `sermon-full-video-text-content-v1` 发布文稿已经包含 `title`、`series`、`speaker`。本轮客户端新增读取可选系列和讲员，仍经既有 release / asset SHA-256 与来源绑定验证；没有修改生产包或升级 wire schema。没有这些可选字段的旧文稿仍可读取。

未选中的发布页只在可见列表行出现时读取文稿元数据，复用现有已验证缓存；不下载音频、不选择页面。内存标题缓存绑定 page ID、英文来源 identity 和默认语言 release hash。读取失败保留目录标题与日期，不从相同日期的其他周次借用讲员。当前页面优先显示当前内容语言的已验证文稿元数据；界面语言切换只翻译界面和版本标记，不翻译证道元数据。
