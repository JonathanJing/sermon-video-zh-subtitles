# Beta 1.26.16（57）

基准为实际分发的 1.26.15（56）冻结源码 `8c71c02c`，不是上一轮 PR 最后的合并 commit。正式版配置保持 1.26.10（51），内容源保持 Firebase Dev。

## 本版变化

- 目录可提供多语言类别，日期下面显示“正式播放版”“YouTube 版”“播客”或自定义类别。支持字段的 App 只需安装一次，此后改 Firebase 类别并刷新目录即可；旧数据保持兼容。
- 全文工具栏正确区分跟随播放和自由阅读；回到当前句只恢复跟随和滚动，不改变播放位置或播放意图。
- 完整大纲与默想资源按来源、内容和发布包身份绑定读取，并支持已有离线缓存；不补译或修改上游内容。
- 源视频与音轨双时钟校验字幕；开发模拟内容与正式审核模式隔离。
- 多窗口共用定位反馈生命周期，仍有前台窗口时，不因另一窗口后台事件清空当前反馈。
- TestFlight 分发核对实际 IPA、Archive、版本、build 与源码身份，不把新 preflight 当作已上传证明。

PR251–255 已在 Beta56 中，本版继续保留。#257 创意计划与 #243 backlog 属于文档。#260 的机器质检发布政策与 v4 消费协议不混入本候选。

## What to Test / 真机验收

1. 安装 1.26.16（57），核对版本。选篇列表及页面标题区的类别应在日期/讲员下面；最近两篇证道显示正式播放版，播客显示播客。已知旧 YouTube 页面继续显示原类别。
2. 保持同一 build，联网刷新目录。改变类别文案后应显示新文案；不更换音源、不改变暂停位置。中英界面显示相应类别，没有该语言时英文兜底。离线使用最近缓存，联网刷新再更新。
3. 播放时全文跟随；手动拖动进入自由阅读；“回到当前播放句”恢复跟随，不跳音频。暂停时也检查该操作不恢复播放。
4. 大纲/默想显示完整内容，大字下可滚动；缓存后的资源断网读取，身份不符不能冒充正式资源。
5. 定位前台反馈、取消、切后台和多窗口切换按现有验收表复测。系统灵动岛在 iOS27.0.1 真机仍未证明恢复；锁屏仍为最近同步字幕，不承诺后台逐句实时更新。

类别契约和数据更新工具见 [说明](../../docs/ios-page-display-categories.zh.md)。四类合成截图不是正式内容，不能用于真机播放验收；新 TestFlight 可用不等于已安装或已验收。
